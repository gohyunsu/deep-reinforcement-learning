Q-learning, DQN과 Rainbow

가치기반 방법은 각 상태·행동의 장기 결과를 Q 함수로 추정한 뒤 높은 Q를 주는 행동을 고른다. 최적 행동가치의 Bellman 식은 \(Q^*(s,a)=\mathbb E[r+\gamma\max_{a'}Q^*(s',a')]\)다. 학습에서는 target \(y=r+\gamma\max_{a'}Q_{target}(s',a')\)에 현재 \(Q_ heta(s,a)\)를 맞추는 TD 회귀를 한다. \(\max\)가 탐험과 정책 선택을 분리하고, Q-learning을 off-policy control로 만든다.

신경망 Q-learning은 연속 표본 상관과 moving target에 취약하다. replay buffer는 과거 transition을 섞어 표본 상관을 낮추고 데이터 재사용을 돕는다. target network는 목표 계산을 느리게 바꾸어 최적화 대상의 진동을 줄인다. 하지만 둘 모두 안정성을 돕는 장치이지 수렴을 보증하는 해결책은 아니다.

max 연산은 잡음이 있는 추정값 중 가장 큰 것을 선택해 과대추정한다. Double DQN은 온라인 네트워크가 행동을 선택하고 target 네트워크가 그 행동을 평가해 선택과 평가의 오차를 분리한다. 이후 N-step return, prioritized replay, dueling network, distributional value 등을 결합한 Rainbow가 구성된다. Distributional RL은 기대값 하나 대신 가능한 반환의 분포 \(Z(s,a)\)를 학습한다. 기대값은 여전히 행동 선택 기준으로 쓸 수 있지만 위험 민감 목표라면 분포 자체의 정보가 유용하다.

개념 흐름

정책평가에서 Q-learning으로

정책 반복과 가치 반복은 평가와 개선을 번갈아 수행한다. Q-learning은 target의 다음 행동에 현재 정책 행동을 쓰지 않고 \(\max_{a'}\)를 쓰므로 behavior policy가 탐험을 하더라도 greedy 목표로 학습한다. terminal transition에는 할인된 다음 Q를 더하지 않는다.

DQN 안정화: replay와 target network

시계열 이웃 샘플의 gradient가 비슷하면 SGD의 독립 표본 가정이 약해진다. replay buffer의 무작위 minibatch는 상관을 완화하고, target network는 bootstrapping target이 매 스텝 급격히 움직이는 현상을 완화한다. 이 둘은 서로 다른 병목을 겨냥한다.

탐험과 Atari 사례

ε-greedy는 대부분 현재 greedy 행동을 선택하고 확률 ε로 무작위 행동을 택한다. ε는 학습 스케줄 및 평가 모드와 구분한다. frame skip은 관측·행동 빈도를 낮춰 계산을 줄이지만 빠른 사건을 놓칠 수 있다.

Double DQN과 과대추정

잡음 있는 추정치 \(\hat Q_a=Q_a+\varepsilon_a\) 중 최댓값의 기대는 보통 실제 최대보다 크다. 선택과 평가를 같은 추정기로 하면 선택된 양의 잡음도 평가에 들어간다. Double DQN target은 \(r+\gamma Q_{target}(s',\arg\max_a Q_{online}(s',a))\)다.

Rainbow 구성 요소

N-step return은 더 긴 실제 보상을 포함하고, prioritized replay는 TD-error가 큰 표본을 더 자주 학습한다. 비균등 샘플링으로 생기는 편향은 importance weight로 보정할 수 있다. dueling head는 상태 가치와 행동 이점을 분리해 행동 간 차이를 학습한다.

Distributional RL과 Rainbow

C51은 반환을 고정된 support 위의 categorical 분포로 근사하고 Bellman projection으로 target 분포를 옮긴다. 여기서 51은 상태 수가 아니라 반환값을 표현하는 atom의 수다. Rainbow는 여러 개선을 결합하므로 성능 향상을 단일 기법 하나에 귀속하지 않는다.

연속 행동으로의 전환

이산 행동이면 모든 행동의 Q를 계산하고 최대를 고를 수 있지만 연속 행동에서는 무한한 후보의 최적화가 필요하다. 다음 강의의 actor network는 Q를 크게 만드는 행동을 직접 제안한다.

시계열 이웃 샘플의 gradient가 비슷하면 SGD의 독립 표본 가정이 약해진다. replay buffer의 무작위 minibatch는 상관을 완화하고, target network는 bootstrapping target이 매 스텝 급격히 움직이는 현상을 완화한다. 이 둘은 서로 다른 병목을 겨냥한다.
