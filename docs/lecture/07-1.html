Model-based RL의 기초

Model-based RL은 행동 뒤의 상태와 보상을 예측하는 환경 모델을 의사결정에 이용한다. 모델을 알고 있다면 여러 행동열의 결과를 미리 비교할 수 있고, 모델을 모르면 실제 경험으로 학습해야 한다. 이 장은 모델의 뜻에서 출발해 행동열 최적화, Cross-Entropy Method(CEM), Model-Predictive Control(MPC), 짧은 가상 rollout으로 정책을 학습하는 방법까지 연결한다.

07-1 / 01

Model-based RL

Model-based RL은 상태 전이를 예측하는 환경 모델을 계획이나 정책 학습에 사용한다.

07-1 / 02

세 가지 질문

모델의 뜻을 정의하고, 모델을 이용한 planning과 가상 데이터 기반 정책 최적화를 구분한다.

07-1 / 03

환경 모델은 무엇인가

시점 \(t\)의 상태 \(s_t\), 행동 \(a_t\), 다음 상태 \(s_{t+1}\), 보상 \(r_t\)를 구분하자. 환경 모델은 조건부 분포 \(P(s_{t+1},r_t\mid s_t,a_t)\)다. 상태 전이 \(P(s_{t+1}\mid s_t,a_t)\)와 보상 분포 \(P(r_t\mid s_t,a_t)\)를 따로 모델링할 수도 있다. 정책 \(\pi(a_t\mid s_t)\)는 행동을 고르는 법칙, 환경 모델은 그 행동의 결과 법칙이다.

바나나를 통에 던지는 로봇을 생각하자. \(s_t\)에는 팔과 바나나의 위치·속도, \(a_t\)에는 관절 명령, \(s_{t+1}\)에는 움직인 뒤의 위치, \(r_t\)에는 통에 들어갔는지가 담긴다. 물리 법칙이 이 전이를 정한다. 신경망 \(P_\phi\)는 그 법칙을 데이터로 근사하는 한 표현일 뿐이다.

영상 한 장을 상태 \(s_t\)로 놓아도 될까?

현재 영상에 가려진 물체나 속도가 없다면 다음 영상의 분포가 과거 영상에도 의존할 수 있다. Markov 상태를 얻으려면 최근 관측 이력이나 기억 변수를 포함해야 한다. 모델을 확률적으로 만들어 불확실성을 표현할 수도 있지만, 빠진 정보를 언제나 복원할 수 있는 것은 아니다.

07-1 / 04

모델을 모르는 환경

실제 로봇이나 Gym 환경에서 에이전트는 행동을 넣고 다음 상태를 관측할 수 있어도 내부 전이 함수를 읽지는 못할 수 있다. 환경의 step 함수는 결과를 돌려주는 인터페이스이지, 임의의 가상 상태와 행동을 무한히 질의할 수 있는 공개 수학식이 아니다.

예를 들어 로봇이 바나나를 약하게 던졌을 때의 실제 결과 하나만 얻었다면 더 강하게 던졌을 때의 결과는 아직 알 수 없다. Model-based RL은 관측 전이로 모델을 학습하거나, 정확한 시뮬레이터를 확보해 이 반사실적 질문에 답한다.

07-1 / 05

모델을 안다면 가능한 일

정확한 모델이 있으면 현재 상태에서 후보 행동을 가상으로 적용해 여러 미래 궤적을 만들 수 있다. 그중 예측 반환이 높은 행동을 고르는 것이 planning이다. 같은 가상 궤적을 정책 학습용 경험으로 쓰는 것도 가능하다.

예를 들어 현재 위치에서 왼쪽·오른쪽으로 움직인 뒤의 상태를 각각 예측하면 두 선택의 장기 보상을 비교할 수 있다. 예측 모델을 데이터로 배운 경우에는 실제 실행 결과를 새 자료로 삼아 다음 계획의 출발점을 고친다.

07-1 / 06

던지기의 반사실적 비교

로봇이 힘 2와 힘 3으로 던지는 두 행동을 고려한다고 하자. 모델이 착지 지점을 각각 통 앞 0.5m와 통 안쪽 0.1m로 예측한다면 힘 3을 선택할 수 있다. 이 비교는 두 행동을 현실에서 모두 시도하지 않고 수행한다.

힘을 연속값으로 조절할 수 있다면 후보 두 개에서 멈출 필요가 없다. 모델 속에서 던지는 힘과 방향을 바꾸어 착지 오차가 가장 작은 입력을 찾을 수 있다. 이 최적화가 다음의 행동열 계획으로 확장된다.

07-1 / 07

모델의 두 사용법

World model을 \(P_\phi(s',r\mid s,a)\)라 쓰자. \(\phi\)는 데이터로 학습하는 파라미터이고, \(s',r\)은 현재 \(s,a\) 뒤의 다음 상태와 보상이다. Planning은 이 모델 안에서 행동 후보를 평가한다. 가상 경험 생성은 모델이 만든 \((s,a,\hat r,\hat s')\)를 정책이나 가치함수의 학습 자료로 이용한다. 모자 기호는 실제 관측이 아닌 예측값을 뜻한다.

앞 방식은 의사결정 시 계산이 들 수 있고, 뒤 방식은 학습 결과를 정책에 저장한다. 같은 모델이라도 어디에 계산을 쓰는지에 따라 장점과 실패 양상이 달라진다.

07-1 / 08

Planning으로 전환

먼저 모델 안에서 여러 행동열의 결과를 비교해 현재 행동을 고르는 planning을 살펴본다.

07-1 / 09

행동열의 목적함수

계획 지평 \(H\)를 앞으로 고려할 행동 수, \(A=(a_t,\ldots,a_{t+H-1})\)를 후보 행동열이라 하자. 모델로 예측한 상태를 \(\hat s_t=s_t\), \(\hat s_{k+1}=f_\phi(\hat s_k,a_k)\)라 쓰고, 예측 보상을 \(\hat r_k=r_\phi(\hat s_k,a_k)\)라 하자. 할인율 \(\gamma\in[0,1]\)에서 한 후보의 점수는

\[\widehat J_H(A\mid s_t)= \sum_{k=t}^{t+H-1}\gamma^{k-t}\hat r_k.\]

바나나를 던질 때는 힘과 방향의 여러 시점 명령이 \(A\)가 된다. Go에서는 앞으로 둘 수를 가정해 결과를 평가한다. 두 문제 모두 모델 속에서 행동열을 비교하지만, 행동공간과 모델의 형태는 다르다.

07-1 / 10

전수 검색의 비용

매 시점 가능한 행동이 \(N\)개라면 길이 \(H\)의 행동열은 \(N^H\)개다. \(N=10\), \(H=6\)만 해도 백만 후보가 되어 각 후보의 상태 전이를 계산해야 한다. 연속 행동에서는 후보가 무한하므로 전수 검색 자체가 불가능하다.

행동 선택지가 열 개씩만 있어도 \(H\)가 한 단계 증가할 때 후보 수는 열 배가 된다. 이 지수적 증가를 피하는 두 접근이 모델의 기울기로 후보를 수정하는 방법과 일부 후보를 표본으로 비교하는 방법이다.

07-1 / 11

미분 가능한 모델에서 행동을 개선하기

전이 \(f_\phi\)와 보상 \(r_\phi\)가 행동에 대해 미분 가능하면 \(\widehat J_H\)를 행동열 \(A\)로 미분해 경사 상승할 수 있다. 두 단계의 단순한 경우 \(s_{t+1}=f_\phi(s_t,a_t)\), \(J=r_\phi(s_t,a_t)+\gamma r_\phi(s_{t+1},a_{t+1})\)라 놓자. 다음 행동 \(a_{t+1}\)을 고정하면 연쇄법칙은

\[\nabla_{a_t}J= \nabla_a r_\phi(s_t,a_t) +\gamma\bigl(D_a f_\phi(s_t,a_t)\bigr)^{\mathsf T} \nabla_s r_\phi(s_{t+1},a_{t+1}).\]

\(D_a f_\phi\)는 행동 변화가 다음 상태를 얼마나 바꾸는지 나타내는 Jacobian이다. 첫 항은 즉시 보상, 둘째 항은 바뀐 다음 상태가 미래 보상에 주는 영향이다. 더 긴 지평에서는 이 경로가 여러 전이를 통과한다.

모델이 미분 가능하면 행동 계획도 항상 잘될까?

접촉이나 충돌에서 예측 함수가 부드럽지 않을 수 있고, 학습 모델의 기울기가 실제 환경의 기울기와 다를 수 있다. 경사는 현재 후보 주변의 국소 정보를 주므로 초기 행동열에 따라 다른 해로 갈 수도 있다.

07-1 / 12

샘플링으로 행동열 비교하기

Random shooting은 \(M\)개의 행동열 \(A^{(1)},\ldots,A^{(M)}\)을 후보분포에서 뽑고, 각 행동열의 \(\widehat J_H\)를 계산해 가장 높은 것을 고른다. 전이 모델의 기울기가 없어도 되며 후보 평가를 병렬화하기 쉽다.

샘플 수 \(M\)이 작으면 좋은 행동열을 놓치고, 크면 모델 rollout 계산이 비싸진다. 예를 들어 두 시점의 좌·우 조향은 네 후보뿐이지만, 관절 12개의 연속 토크를 20단계 정하면 균일 표본이 쓸 만한 좁은 영역에 들어갈 확률이 작다.

07-1 / 13

기울기와 샘플링의 절충

기울기 기반 계획은 한 후보에서 어떤 방향이 좋아지는지 이용하므로 고차원 행동열을 다룰 여지가 있다. 대신 미분 가능한 모델과 믿을 만한 기울기가 필요하다. 샘플링은 불연속 보상이나 black-box 모델에도 쓸 수 있고 병렬 계산이 쉽지만 차원이 높아지면 후보가 희박해진다.

행동열 길이 \(H\)와 행동 차원 \(d_a\)를 곱한 \(Hd_a\)가 실제 최적화 변수의 수다. 같은 로봇이라도 지평을 두 배로 늘리면 검색 차원이 두 배가 된다. 연속 제어에서는 이 차원이 커질수록 균일 표본이 유용한 궤적을 찾기 어려워져, 다음 CEM처럼 후보분포를 적응적으로 옮긴다.

07-1 / 14

Cross-Entropy Method

CEM은 random shooting의 후보분포를 반복 개선한다. 처음에는 행동열 \(A\in\mathbb R^{Hd_a}\)을 Gaussian \(q_0(A)\)에서 \(M\)개 뽑고, 모델 점수 상위 \(K\)개의 elite를 남긴다. 반복 \(j\)의 elite를 \(A^{(1)}_{\mathrm e},\ldots,A^{(K)}_{\mathrm e}\)라 하면 대각 Gaussian의 평균과 분산을

\[\mu_{j+1}=\frac1K\sum_{i=1}^K A^{(i)}_{\mathrm e}, \qquad \sigma_{j+1}^2=\frac1K\sum_{i=1}^K \bigl(A^{(i)}_{\mathrm e}-\mu_{j+1}\bigr)^{\odot2}\]

로 다시 맞춘다. \(^{\odot2}\)는 좌표별 제곱이다. 새 분포에서 다시 후보를 뽑으면 이전 elite 부근을 더 집중적으로 탐색한다. 이는 미분이 아니라 좋은 표본의 통계량으로 분포를 바꾸는 절차다.

CEM의 elite가 한쪽 국소해로 몰리면?

분산이 너무 빨리 줄면 다른 좋은 경로를 더 이상 샘플링하지 못한다. 최소 분산을 두거나 이전 분포와 새 분포를 섞고, 여러 초기화로 비교할 수 있다. 행동 경계 밖 표본은 잘라내거나 적절히 변환해야 한다.

07-1 / 15

CEM을 어디에 쓰는가

한 번의 CEM 반복은 후보 \(M\)개를 모델로 평가하고 상위 \(K\)개로 분포를 다시 맞춘다. 이를 \(J\)번 반복하면 대략 \(JM\)개 행동열의 모델 rollout이 필요하다. 후보별 평가는 병렬화할 수 있지만, 분포를 갱신하는 반복은 순서대로 진행된다.

고차원에서는 독립 좌표 Gaussian이 좌표 간 협력을 충분히 표현하지 못할 수도 있다. 예를 들어 두 관절을 동시에 맞춰야 하는 접촉 행동은 각 관절을 따로 흔드는 표본보다 상관된 움직임이 중요하다. 계획의 품질과 온라인 지연을 함께 평가한다.

07-1 / 16

정확한 모델이라는 가정

지금까지 후보 행동열의 점수는 모델이 계산했다. 실제 환경의 \(P\)와 모델 \(P_\phi\)가 다르면 그 점수는 참 반환이 아니다. 특히 최적화기는 모델이 잘못 높게 예측한 후보를 적극적으로 찾을 수 있다.

모델을 모르는 일반적인 상황에서는 실제 전이 데이터를 모아 \(P_\phi\)를 학습한다. 이후 계획으로 방문한 새 상태를 다시 데이터에 넣어 모델의 범위를 넓히는 폐회로가 필요하다.

07-1 / 17

전이 모델을 데이터로 학습하기

실제 경험 집합을 \(\mathcal D=\{(s_i,a_i,s'_i)\}_{i=1}^N\)이라 하자. 결정론적 예측 \(f_\phi(s,a)\)는 다음 상태와의 제곱오차 \(\sum_i\|f_\phi(s_i,a_i)-s'_i\|_2^2\)를 줄여 학습할 수 있다. 확률 모델 \(P_\phi(s'\mid s,a)\)는 \(\sum_i\log P_\phi(s'_i\mid s_i,a_i)\)를 높여 학습한다.

제곱오차가 왜 자연스러운지 유도해 보자. 다음 상태의 차원을 \(d_s\)라 하고 아래와 같이 가정하자.

\[P_\phi(s'\mid s,a)=\mathcal N\!\left(f_\phi(s,a),\sigma^2I\right).\]

\(\sigma^2\)는 모든 좌표에 공통인 고정 잡음 분산이고 \(I\)는 단위행렬이다. 이 분포의 음의 로그우도는

\[-\log P_\phi(s'\mid s,a) =\frac{d_s}{2}\log(2\pi\sigma^2) +\frac{\|s'-f_\phi(s,a)\|_2^2}{2\sigma^2}.\]

첫 항과 분모의 \(\sigma^2\)가 고정되어 있으므로 우도 최대화는 제곱오차 최소화와 같다. 실제 전이가 여러 결과를 낳는데 평균 하나만 예측하면 어느 결과도 제대로 나타내지 못할 수 있다. 계획에서 중요한 것은 훈련 전이의 평균 오차뿐 아니라 계획이 방문할 상태·행동에서의 예측이다.

07-1 / 18

모델 오류가 계획에 들어오는 경로

모델은 \(\mathcal D\)의 상태·행동에서 학습하지만 계획은 새 후보를 탐색한다. 훈련 분포를 \(d_{\mathcal D}\), 계획으로 방문할 분포를 \(d_{\mathrm{plan}}\)이라 하면 두 분포가 다를 수 있다. 그림의 절벽에서는 데이터가 거의 없는 방향의 높이를 모델이 과대평가하자, 계획기가 바로 그 방향을 선택한다.

오류 누적도 보자. 참 결정론적 전이를 \(f\), 학습 모델을 \(\hat f\)라 하고, 각 지점의 한 단계 모델 오차가 \(\|\hat f(s,a)-f(s,a)\|\le\varepsilon_m\)라고 가정하자. 참 전이가 상태에 대해 \(L\)-Lipschitz이면 같은 행동열의 \(k\)단계 상태 오차 \(e_k\)는 \(e_0=0\), \(e_{k+1}\le L e_k+\varepsilon_m\)을 만족한다. 따라서

\[e_H\le\varepsilon_m\sum_{j=0}^{H-1}L^j.\]

이 경계는 방문하는 영역 전체에서 오차 가정이 성립할 때만 유효하다. 데이터 밖에서는 \(\varepsilon_m\) 자체가 클 수 있어 긴 rollout의 예측을 더 조심해야 한다.

07-1 / 19

계획으로 수집한 데이터를 다시 넣기

한 번의 계획 뒤 첫 행동을 실제 환경에서 실행해 \((s,a,r,s')\)를 관측하고 \(\mathcal D\)에 더한다. 그런 다음 전이와 보상 모델을 갱신한다. 계획이 자주 선택하는 상태·행동에 실제 표본이 쌓이므로 학습 분포도 그쪽으로 이동한다.

로봇에서 시험 자체가 위험하면 불확실성이 큰 후보에 벌점을 주거나 안전 제약을 둔다. 이렇게 하면 탐색 가능 범위를 통제하면서 실제 전이가 알려 준 구간에서 모델을 고칠 수 있다.

07-1 / 20

절벽 사례의 교정

처음에는 오른쪽으로 가면 위로 올라갈 수 있다고 모델이 잘못 예측했다고 하자. 계획기가 오른쪽을 선택하고 실제로는 절벽에서 멈춘 기록을 얻으면, 그 전이를 추가한 뒤 모델은 해당 경로의 점수를 낮출 수 있다. 최종 정책이 안전한 위쪽 경로를 선택하는 변화는 실제 전이로 모델을 고친 결과다.

절벽 그림의 변화는 계획 → 실행 → 전이 기록 → 모델 갱신 → 재계획의 폐회로를 보여 준다. 계획기가 높은 점수를 준 경로에서 실제로 낮은 결과가 관측되면, 다음 반복의 행동열 순위도 바뀐다.

07-1 / 21

Open-loop와 closed-loop

Open-loop 계획은 현재 상태에서 행동열 \((a_t,\ldots,a_{t+H-1})\)을 정하고 관측이 달라져도 그대로 실행한다. Closed-loop 제어는 다음 관측을 받아 남은 계획을 고친다. 모델이 완벽하지 않거나 외부 교란이 있으면 두 방식은 크게 달라진다.

자율주행차가 3초치 조향을 한꺼번에 고정하면 앞차가 갑자기 멈춰도 반응하지 못한다. 매 순간 새 관측에 맞춰 계획을 다시 만들면 늦게 드러난 장애물에 대응할 수 있다.

07-1 / 22

Model-Predictive Control

MPC는 현재 상태에서 길이 \(H\)의 최적 행동열을 구하되 첫 행동만 실행한다. 다음 실제 상태 \(s_{t+1}\)을 관측하면 다시 길이 \(H\)를 계획한다. 매 시점 전이 \((s_t,a_t,r_t,s_{t+1})\)을 데이터에 추가하고 모델을 갱신할 수도 있다.

재계획은 앞서 예측한 \(s_{t+1}\)과 실제 \(s_{t+1}\)의 차이를 바로 반영한다. 대신 매 제어 시점에 CEM 같은 최적화를 반복하므로 계산이 비싸다. 제어 주기 안에 답을 내는지와 모델이 얼마나 앞까지 맞는지를 함께 정해야 한다.

재계획하면 모델 오차가 모두 사라질까?

매번 첫 행동의 결과를 새 관측으로 교정하지만, 그 첫 행동을 고르는 데 사용한 미래 예측은 여전히 틀릴 수 있다. 특히 실제로 한 번 실행하면 되돌릴 수 없는 위험한 행동은 다음 시점의 재계획으로 복구할 수 없다.

07-1 / 23

Model-based planning의 경계

MPC는 전이 모델과 보상 모델을 이용해 현재 행동을 정한다. 목표 위치가 바뀌어 보상 함수가 달라져도 같은 전이 모델로 새 목적함수를 계획할 수 있다. 이는 환경의 움직임과 과업의 목표를 분리해 둔 이점이다.

계획 지평이 길면 계산량과 예측 오차가 커진다. 다음 장에서는 짧은 지평 뒤의 장기 성과를 가치함수로 요약해 이 문제를 다룬다.

07-1 / 24

정책 학습으로 전환

다음은 모델로 만든 가상 경험을 정책 학습에 사용하는 방법이다.

07-1 / 25

계획 결과를 정책으로 압축하기

계획기가 상태 \(s\)에서 고른 첫 행동을 \(a_{\mathrm{plan}}(s)\)라 하자. 정책 \(\pi_\theta\)를 \(\mathcal L(\theta)=E_s[\|\pi_\theta(s)-a_{\mathrm{plan}}(s)\|^2]\)로 학습하면 실행 시 비싼 계획을 한 번의 정책 계산으로 대체할 수 있다. 이는 planner의 행동을 지도학습으로 distillation하는 방식이다.

Distillation은 계획에 쓰던 계산을 학습 시점으로 옮긴다. 실행은 빨라지지만 정책이 따라 하는 목표의 품질은 계획 지평과 모델의 예측에 의해 정해진다. 긴 과업에서는 끝 상태의 가치를 넣어 planner의 행동부터 개선할 수 있다.

07-1 / 26

짧은 가상 rollout을 어디서 시작할까

모델에서 긴 궤적을 한 번에 만들면 예측 오차가 쌓인다. 초기 상태에서만 짧게 시작하면 실제 정책이 나중에 방문하는 상태를 충분히 다루지 못한다. 실제 replay의 여러 시점 상태를 시작점으로 뽑아 각각 짧은 rollout을 만들면 두 문제를 절충할 수 있다.

예를 들어 실제 50단계 궤적의 10, 25, 40번째 상태에서 각각 5단계만 가상으로 뻗는다. 초기 상태 하나에서 50단계를 예측하는 경우보다 각 가상 궤적이 실제 관측에 가까운 곳에서 출발한다. 학습기는 접근·접촉·완료처럼 서로 다른 진행 단계의 후속 결과를 보게 된다.

07-1 / 27

환경 자료와 모델 자료의 순환

실제 전이 집합을 \(\mathcal D_{\mathrm{env}}\), 모델이 만든 전이 집합을 \(\mathcal D_{\mathrm{model}}\)이라 하자. 현재 정책 \(\pi_\theta\)로 현실에서 데이터를 모아 전자를 갱신하고, 그 데이터로 모델 \(P_\phi\)를 학습한다. 실제 상태를 시작점으로 모델 속에서 \(\pi_\theta\)를 실행해 후자를 만든 뒤, actor와 critic을 가상 자료로 갱신한다.

가상 전이는 실제 환경을 다시 호출하지 않고 업데이트용 표본을 늘린다. 그러나 critic의 목표 \(r+\gamma V(s')\)에 예측 \(\hat r,\hat s'\)를 넣으면 보상 오차와 상태 오차가 함께 전파된다. 실제 자료를 모델 교정의 기준으로 유지하고, 모델 자료의 지평과 비중을 조절하는 이유다.

07-1 / 28

언제 모델이 유리한가

상태 전이가 비교적 규칙적이고 실제 상호작용이 비싼 로봇 제어에서는 모델 학습의 비용을 여러 가상 시도에 나누어 쓸 수 있다. 전이 모델은 보상 라벨 없이도 연속 관측으로 학습할 수 있고, 목표 보상이 달라져도 일부 재사용할 수 있다.

모델 학습의 비용은 예측 대상에 달려 있다. 픽셀 전체를 복원하면 배경·조명까지 맞혀야 하지만, 제어에는 물체 위치와 접촉 같은 일부 특징만 중요할 수 있다. 뒤의 TD-MPC는 이 차이에 맞춰 보상과 가치에 필요한 잠재 동역학을 배운다.

07-1 / 29

두 경로의 정리

Model-based RL은 참 모델 또는 학습 모델로 후보 행동의 미래를 평가한다. Planning은 행동열을 경사나 CEM으로 최적화하고 MPC로 매 시점 재계획한다. Policy optimization은 모델이 만든 짧은 가상 경험으로 actor와 critic을 갱신한다.

계산의 위치가 두 경로를 구분한다. Dreamer는 잠재공간의 가상 경험으로 실행할 정책을 학습하고, TD-MPC는 짧은 잠재 계획에 terminal value를 붙여 현재 행동을 고른다. 두 알고리즘을 이 기준으로 다음 장에서 비교한다.
