Sim-to-Real I

시뮬레이터에서는 안전하게 수많은 시행을 할 수 있지만 실제 로봇의 센서와 물리는 다르다. Sim-to-real의 문제는 시뮬레이션에서 얻은 정책이 현실에서도 같은 결과를 내도록 이 격차를 다루는 것이다. 시스템 식별, domain randomization, 시각·동역학 격차를 함께 줄이는 환경 grounding을 순서대로 본다.

13-1 / 01

현실로 옮기는 학습

관측 \(o\)에서 행동 \(a\)를 고르는 정책 \(\pi(a\mid o)\)를 시뮬레이터에서 훈련한 뒤 실제 로봇에 적용한다. 입력 영상과 행동 후 전이가 조금만 달라도 정책은 학습하지 않은 상태로 이동할 수 있다. 학습 때의 성공률과 실제 로봇의 성공률을 별도로 기록해야 한다.

13-1 / 02

실제 환경 RL의 가능성

DayDreamer처럼 실제 로봇 자료로 world model을 학습해 현장에서 정책을 개선하는 방법도 있다. 이는 sim-to-real과 다른 출발점이다. 실제 학습이 가능해도 안전한 초기 행동, reset, 장비 마모가 제약이다.

13-1 / 03

짧은 시간의 실제 보행 학습

실물 로봇에서 model-free RL로 보행을 빠르게 학습한 사례는 병렬 수집, 보상 설계, 제어 인터페이스 등 구체적 조건의 결과다. “20분”이라는 숫자를 모든 로봇 작업의 보편적 학습 시간으로 받아들이면 안 된다.

13-1 / 04

실제 시행의 비용

시뮬레이션은 실패 후 즉시 reset할 수 있지만 로봇은 넘어지거나 부품이 손상될 수 있다. 실제 학습의 환경 단계 수뿐 아니라 사람이 개입한 횟수와 물리적 위험을 함께 세어야 한다.

13-1 / 05

시뮬레이션을 쓰는 이유

시뮬레이션은 안전한 대량 경험, 원하는 초기 상태의 반복, 촘촘한 보상을 제공한다. 반면 실제 세계의 마찰·센서 지연·물체 변형을 완전히 재현하지 못한다. 학습의 편리함과 배포 시 분포 차이가 함께 생긴다.

13-1 / 06

Sim-to-real gap

시뮬레이터 전이를 \(P_{\rm sim}(s'\mid s,a)\), 실제 전이를 \(P_{\rm real}(s'\mid s,a)\)라 하자. 두 분포가 다르거나 관측 영상의 분포가 다르면 시뮬레이션 정책의 반환이 현실에서 낮아질 수 있다. 한 단계의 작은 오차도 닫힌 고리 실행에서는 다음 상태를 바꿔 누적된다.

13-1 / 07

완벽한 시뮬레이터가 어려운 이유

마찰·질량·모터 gain 같은 파라미터를 정확히 모를 수 있고 현실의 모든 변화도 열거할 수 없다. 물리 엔진의 접촉 모델 자체도 근사다. System identification은 파라미터를 맞추고, domain randomization은 여러 변형에서 견디게 하며, domain adaptation은 관측된 현실과 표현·전이를 맞춘다.

13-1 / 08

System identification

입력 행동 \(a_{0:T-1}\)에 대한 실제 상태 \(s_{1:T}\)를 관찰해 시뮬레이터 파라미터 \(\xi\)를 찾는다. 예컨대 다음 오차를 줄인다.

\[\hat\xi=\arg\min_\xi\sum_{t=0}^{T-1} \|s^{\rm sim}_{t+1}(\xi)-s^{\rm real}_{t+1}\|^2.\]

서로 다른 파라미터가 같은 관측을 설명하면 식별이 불완전하고, 시간이 지나 마모되면 다시 조정해야 한다.

13-1 / 09

세 접근의 역할 구분

식별만으로 현실의 모든 조명·마찰·물체 차이를 맞추기 어렵다. 무작위화는 정책이 여러 환경을 견디게 하고, adaptation은 실제 관측으로 남은 격차를 줄인다. 세 접근은 상호 배타적인 이름이 아니라 함께 쓸 수 있는 도구다.

13-1 / 10

Domain randomization

시뮬레이션마다 물리·시각 파라미터 \(\xi\sim p_{\rm train}(\xi)\)를 뽑아 \(\mathbb E_\xi[J_{\xi}(\pi)]\)를 높인다. 실제 환경이 훈련 분포 안에 있거나 그 근처면 강건성이 좋아질 수 있다. 범위를 지나치게 넓히면 하나의 정책이 모든 경우를 잘하기 어렵다.

무작위화 범위를 넓힐수록 안전한가?

그렇지 않다. 예를 들어 바닥 마찰을 거의 0부터 매우 큰 값까지 뽑으면 모든 경우에 잘 걷는 공통 정책이 없을 수도 있다. 알려진 하드웨어 범위에서 시작해 실제 평가 결과와 실패 조건에 맞춰 범위를 조정해야 한다. 분포 밖의 현실 조건은 넓은 무작위화만으로 보장되지 않는다.

13-1 / 11

물리 무작위화의 보행 효과

질량, 마찰, 모터 응답, 지형을 바꾸며 훈련하면 실제 로봇의 미지 특성에도 대응할 수 있다. RMA는 이런 다양한 환경에서 보행 정책과 적응 모듈을 학습한 사례다. 무작위화의 효과는 사용한 실제 지형과 훈련 범위를 함께 보고 해석한다. RMA 연구

13-1 / 12

시각 무작위화

텍스처·조명·배경·카메라 위치를 바꾸면 정책이 한 렌더링의 우연한 단서에 의존하는 일을 줄일 수 있다. 그러나 임의의 색 변화가 실제 카메라의 반사·가림·노이즈를 모두 재현하지는 못한다. 시각 입력과 행동의 관련 정보를 보존하는지도 확인한다.

13-1 / 13

실제 장면의 복잡성

현실 영상에는 그림자, 반사, 움직이는 물체, 카메라 흔들림이 함께 있다. 시뮬레이션 영상이 다양해도 센서의 깊이 오류나 접촉 때의 가림이 빠질 수 있다. 시각 격차는 단순한 색상 차이보다 넓다.

13-1 / 14

시각 격차의 어려움

현실을 모든 모습으로 무작위화하기 어렵기 때문에 실제 자료로 표현을 보정할 수 있다. 중요한 것은 이미지가 사실적으로 보이는 것만이 아니라 정책에 필요한 물체 위치·형상 정보가 보존되는 것이다.

13-1 / 15

두 격차를 함께 다루기

영상 분포만 맞아도 같은 행동이 현실에서 다르게 움직일 수 있고, 동역학만 맞아도 정책이 영상을 잘못 읽을 수 있다. 시각과 물리 격차를 각각 정의한 뒤 같은 정책 루프 안에서 함께 줄여야 한다.

13-1 / 16

Source와 target

Source는 학습하기 쉬운 시뮬레이터, target은 실제 로봇이다. IDAPT는 source의 관측을 target 영상처럼 바꾸고, target에서 실행할 행동을 source에서 같은 효과를 내는 행동으로 바꾼다. 이 변환을 넣은 source에서 정책을 학습하므로 배포 정책은 target 관측과 행동을 그대로 사용한다. IDAPT 논문

13-1 / 17

행동의 의미 차이

같은 숫자의 명령 \(a^T\)도 실제 로봇과 시뮬레이터에서 다른 결과를 낼 수 있다. IDAPT는 정책이 target용 행동 \(a^T\)를 내면 시뮬레이터 내부에서 이를 \(a^S\)로 바꿔 source 전이가 target 전이를 닮도록 한다. 실제 배포 때 이 내부 변환을 로봇에 적용하는 구조는 아니다.

13-1 / 18

Action transformation

관측변환을 \(G:o^S\mapsto\hat o^T\)라 하고 action transformation을 \(F:(\hat o^T,a^T)\mapsto\hat a^S\)라 하자. 정책은 \(a^T=\pi(\hat o^T)\)를 내고, source에는 \(\hat a^S=F(\hat o^T,a^T)\)를 실행한다. 목표는 행동값 자체가 같아지는 것이 아니라 변환된 source의 다음 관측이 같은 \(a^T\)를 실행한 target 결과에 가까워지는 것이다.

13-1 / 19

동역학 grounding

실제 target의 \((o_t^T,a_t^T,o_{t+1}^T)\)와 변환된 source의 \((\hat o_t^T,a_t^T,\hat o_{t+1}^T)\)를 비교해 \(F\)를 조정한다. 두 환경의 상태를 완전히 동일하게 관측할 필요는 없지만, 전이를 비교할 수 있는 공통 표현은 필요하다. IDAPT는 정책의 영상 특징을 이 비교에 사용한다.

13-1 / 20

Visual transformation

IDAPT의 \(G\)는 source 영상에서 target처럼 보이는 영상으로 변환한다. 정책은 변환된 영상으로 학습하고 실제 target 영상으로 실행한다. 변환 과정에서 물체 위치가 바뀌면 정책이 잘못된 행동을 하므로 질감의 유사성과 과제에 필요한 기하 구조를 함께 확인한다.

13-1 / 21

왕복 변환의 제약

Cycle consistency나 상태 재구성 손실은 영상 변환이 과제에 필요한 구조를 없애지 않게 돕는다. 원본→변환→역변환이 원본과 가깝더라도 완벽한 의미 보존이 증명되는 것은 아니다. 목표 물체와 접촉 정보가 유지되는지 별도 검사한다.

13-1 / 22

Grounded environment

행동·시각 변환을 적용한 source는 target과 더 비슷한 학습 환경이 된다. 이 환경에서 정책을 학습하면 실제에서의 입력과 결과를 더 잘 예측할 수 있다. 격차가 0이 되었다고 가정하지 않고 반복 배포로 확인한다.

13-1 / 23

Grounding과 정책 학습의 반복

실제 자료로 source를 맞추고, 맞춘 source에서 정책을 훈련한 뒤, 새 정책으로 실제 자료를 다시 모은다. 정책이 바뀌면 방문 상태도 바뀌므로 초기 target 자료만으로 충분하지 않을 수 있다.

정책이 변환 모델의 오류를 이용하면?

잘못 보정된 source에서만 높은 보상을 주는 행동이 생길 수 있다. 새 정책을 target에서 실행해 그 상태의 실제 전이를 수집하고 \(G,F\)를 다시 맞추는 반복이 이 문제를 줄인다. 다만 재수집은 오류를 발견할 기회이지 안전성의 자동 보장은 아니다.

13-1 / 24

환경을 먼저 보정하기

현재 정책이 방문한 target 상태·전이와 source의 대응 결과를 비교해 변환을 학습한다. 보정 단계는 정책 자체의 보상을 최적화하는 단계와 구분된다. 잘못 짝지은 관측은 오히려 source를 왜곡할 수 있다.

13-1 / 25

보정된 환경에서 정책 훈련

Target과 비슷해진 source에서 풍부한 시뮬레이션 경험으로 정책을 개선한다. 새 정책이 기존 target 자료 밖으로 나가면 다시 격차가 생길 수 있다. 학습과 grounding을 번갈아 하는 이유다.

13-1 / 26

반복적 격차 감소

한 번의 보정으로 끝나지 않고 새 실제 실행 자료를 반영한다. 반복 횟수가 늘수록 정책이 방문하는 상태에서의 격차가 줄어들 수 있다. 모든 가능한 상태에서의 완전한 일치를 주장하는 것은 아니다.

13-1 / 27

쉬운 target과 어려운 target

시각 차이만 큰 경우와 질량·마찰도 함께 다른 경우는 전이 난도가 다르다. 한 환경에서 성공한 변환을 더 어려운 target에 그대로 적용하면 실패할 수 있다. 두 종류의 격차를 분리해 평가한다.

13-1 / 28

어떤 차이를 넣었는가

렌더러·시점·배경·색은 관측 격차를, 물체 질량 변화는 동역학 격차를 만든다. 같은 물체를 보더라도 관측만 달라진 경우와 동일한 행동 뒤 결과가 달라진 경우를 구별해야 원인을 진단할 수 있다.
