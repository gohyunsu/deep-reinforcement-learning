Sim-to-Real II

현실 격차는 하나의 원인으로만 생기지 않는다. 가구 조립의 접촉 오차에는 사람의 online correction, 보행의 미지 지형에는 실시간 적응, 대량 정책 학습에는 병렬 시뮬레이션과 교육과정이 쓰인다. 각 사례에서 무엇을 현실에서 관측하고 어떤 정보를 시뮬레이션에서만 쓰는지를 구분한다.

13-2 / 01

현실 배포의 두 분야

이 장은 조립 조작과 네발 보행을 비교한다. 조립은 접촉과 비가역적 상태가, 보행은 빠른 제어와 지형 변화가 어렵다. 같은 sim-to-real 문제라도 관측·행동·실패 비용에 따라 해법이 달라진다.

13-2 / 02

조립 작업의 난도

나사 조임·삽입·뒤집기는 작은 위치 오차가 실패로 이어진다. 한 단계가 실패하면 앞 상태로 돌아가기 어려울 수도 있다. 정책은 시뮬레이션에서 높은 보상을 받아도 실제 접촉에서는 다르게 움직일 수 있다.

13-2 / 03

TRANSIC의 목표

TRANSIC은 시뮬레이션 정책을 현실에서 실행하면서 사람이 필요한 순간 교정한 자료로 잔여 오차를 학습한다. 모든 현실 동작을 시연하는 대신 시뮬레이션 정책이 틀린 부분에 사람의 노력을 집중한다. TRANSIC 논문

13-2 / 04

정책과 교정의 결합

기본 정책 \(a_{\rm base}=\pi_{\rm sim}(o)\)에 교정 정책의 출력 \(\Delta a=\pi_{\rm res}(o)\)를 더하거나 선택적으로 적용한다. 최종 행동 \(a=a_{\rm base}+\Delta a\)는 두 모델의 역할을 드러낸다. 실제 구현에서는 안전 범위와 교정 실행 조건을 명시해야 한다.

13-2 / 05

전이 설계의 네 요소

강한 시뮬레이션 정책, domain randomization, 현실과 차이가 작은 관측·제어 인터페이스, 실제 교정 자료가 결합된다. 어느 하나가 약하면 잔차 정책이 감당해야 할 오류가 너무 커질 수 있다. 작은 현실 자료만으로 처음부터 모든 조립을 배우는 것과 다르다.

13-2 / 06

시뮬레이션 정책 훈련

FurnitureSim에서 PPO로 기본 정책을 학습한다. 시뮬레이터는 실제 배포에서는 보이지 않는 정확한 물체 상태와 촘촘한 과제 보상을 제공할 수 있다. Privileged 정보가 학습에 쓰였는지와 배포 정책의 실제 입력이 무엇인지는 구분해야 한다.

13-2 / 07

Domain randomization

물체 위치·마찰·카메라·제어 지연 등을 바꾸며 학습하면 한 시뮬레이터 설정만 외우는 것을 줄인다. 실제 접촉의 모든 차이를 포함할 수 없으므로 현실 실행 자료에서 남은 실패를 확인한다.

13-2 / 08

Point cloud와 관절 위치 제어

정책의 입력을 3차원 점 집합으로, 출력을 관절 목표 위치로 정한다. RGB 영상의 질감 차이를 줄이고 제어 인터페이스의 모델 오차를 줄이려는 선택이다. 센서 품질과 3D 점의 정렬이 나쁘면 이 장점이 사라질 수 있다.

13-2 / 09

Point cloud의 격차

기하 구조에 집중한 점 집합은 배경 색·조명 변화에 덜 민감할 수 있다. 하지만 깊이 센서의 누락, 반사 물체, 가림, 카메라 보정 오차는 여전히 남는다. Point cloud regularization은 시뮬레이션 점과 실제 점의 차이를 견디도록 학습한다.

13-2 / 10

관절 목표와 말단 목표

말단(end-effector) 위치를 직접 지정하려면 역기구학·운동학 모델과 로봇 보정에 의존할 수 있다. 관절 위치 목표는 일부 모델 오차를 줄일 수 있지만 작업 공간에서 정확한 접촉을 자동으로 보장하지 않는다. 어느 인터페이스가 나은지는 로봇 제어기의 품질에 달려 있다.

13-2 / 11

견고한 기본 정책의 역할

현실 교정 전에 기본 정책만으로 어느 단계까지 성공하는지 측정한다. 기본 정책이 거의 모든 상태에서 실패하면 작은 잔차만 배우는 방식은 어렵다. 교정 정책은 기본 정책의 성공 영역을 넓히는 역할을 한다.

13-2 / 12

사람이 실행 중 개입하기

실제 로봇의 실행을 보며 사람이 실패가 예상되는 순간 행동을 교정한다. 이 자료는 완전한 시연보다 기본 정책이 잘못한 상태를 집중적으로 포함한다. 개입 시점과 개입 후의 상태를 함께 기록해야 교정의 맥락을 배운다.

13-2 / 13

Residual policy

잔차 정책은 기본 행동에서 얼마나 바꿔야 하는지 학습한다. \(\Delta a=0\)이면 기본 정책을 그대로 사용하고, 필요할 때만 교정을 더한다. 큰 잔차가 계속 필요하다면 기본 정책의 표현·관측·제어 구조를 다시 살펴야 한다.

13-2 / 14

FurnitureBench 평가

안정화, 잡기, 삽입, 나사 조임 같은 부분 작업별 성공률을 측정한다. 시연 수, 실제 평가 episode 수, 초기 물체 배치를 함께 기록해야 방법을 공정하게 비교할 수 있다. 한 작업의 성공률을 전체 조립 성공률로 착각하지 않는다.

13-2 / 15

보고된 성공률의 의미

강의 그림의 약 80% 성공은 해당 벤치마크와 평가 조건에서 기본 정책과 사람 교정의 결합 효과를 보여 준다. 실제 환경 자료만으로 fine-tune한 방법과 비교할 때 자료량과 개입 방식도 확인해야 한다. 다른 로봇·부품에서 같은 수치를 기대할 근거는 아니다.

13-2 / 16

Point cloud regularization의 기여

일부 격차는 잔차만으로 보완하기 어렵고 기본 정책의 관측 표현을 강건하게 해야 한다. 점 집합을 실제처럼 수집·정렬하는 과정 자체가 수고롭다. 성능 증가와 자료 준비 비용을 함께 읽는다.

13-2 / 17

실패 사례

그리퍼 변형, 삽입 위치 오류, 과도한 나사 회전, 불안정한 잡기처럼 물리 접촉의 세부가 실패 원인이 될 수 있다. 실패 장면을 범주별로 모으면 관측 오류인지 제어 오류인지, 잔차로 고칠 수 있는지 판단하기 쉽다.

13-2 / 18

적용 범위의 제한

탁상 조립과 단순 그리퍼에서의 결과를 복잡한 양손 조작으로 바로 확장하기 어렵다. 사람의 개입 시간과 paired point cloud 획득도 비용이다. RGB를 생략하면 색·문자처럼 과제에 필요한 시각 정보가 빠질 수 있다.

13-2 / 19

조립에서의 교훈

강한 시뮬레이션 정책을 먼저 만들고 현실의 실패 상태에서 사람 교정을 배워 격차를 줄인다. 관측과 제어 인터페이스 설계가 잔차 학습만큼 중요하다. 성공률뿐 아니라 사람이 몇 번 개입했는지 보고해야 한다.

13-2 / 20

네발 보행으로 전환

보행은 작은 시간 간격의 안정적인 제어가 필요하다. 시뮬레이션에서 대량 병렬 학습을 하고 실제 지형에 배포하는 사례를 본다. 조립과 달리 접촉이 매 걸음 반복되어 강건한 저수준 정책이 중요하다.

13-2 / 21

대량 병렬 보행 학습

수천 로봇을 한 GPU에서 동시에 시뮬레이션하면 환경 단계 수를 짧은 실제 시간 안에 모을 수 있다. 시뮬레이션에서의 학습 시간과 실제 로봇의 배포 성능을 별도 수치로 본다. 대량 병렬 보행 연구

13-2 / 22

보행 MDP

상태에는 관절 각도·속도·몸체 움직임과 명령 속도가, 행동에는 관절 목표나 토크가 들어간다. 정책은 전진·회전 명령을 따르면서 넘어지지 않아야 한다. 제어 주파수 50Hz는 행동 하나를 약 0.02초마다 갱신한다는 뜻이다.

13-2 / 23

병렬 환경

\(N\)개의 시뮬레이터가 서로 다른 초기 자세와 지형을 가진다. 한 정책이 모든 관측을 batch로 받아 한 번에 행동을 계산한다. 병렬성은 시간당 수집량을 높이지만 환경 다양성과 sample efficiency를 자동으로 높이는 것은 아니다.

13-2 / 24

관측과 행동의 정렬

명령 속도, 몸체·관절 상태, 직전 행동, 지형 스캔을 관측으로 쓴다. 행동이 관절 위치 목표라면 정책 출력과 실제 저수준 제어기의 단위를 맞춰야 한다. 시뮬레이션과 현실에서 동일한 센서가 제공되는지도 확인한다.

13-2 / 25

보상 항의 의미

명령 추종, 움직임의 매끄러움, 충돌 회피, 보폭을 함께 보상한다. 가중치가 잘못되면 빠르지만 불안정하거나 안정적이지만 움직이지 않는 정책이 나온다. 전체 보상뿐 아니라 항별 값과 실제 보행 품질을 봐야 한다.

13-2 / 26

지형 생성과 교육과정

평지에서 시작해 경사·턱·거친 표면으로 지형을 넓힌다. 처음부터 어려운 지형만 주면 성공 표본이 부족할 수 있다. 교육과정은 난도를 조금씩 올려 정책이 이전 능력 위에서 학습하게 한다.

13-2 / 27

병렬 PPO의 batch

환경 \(N=4096\)개에서 각각 \(T=24\)단계를 모으면 한 rollout에 \(NT=98{,}304\)개 전이가 생긴다. 모든 환경의 관측을 [N,d_s]로 모아 정책을 한 번 실행해 [N,d_a] 행동을 얻는다. PPO의 advantage와 종료 마스크는 환경 축별로 계산해야 서로 다른 로봇 궤적이 섞이지 않는다.

13-2 / 28

큰 batch의 효과

많은 병렬 전이는 정책경사 추정의 표본 잡음을 줄일 수 있다. 하지만 batch가 크면 한 update 사이에 환경을 더 오래 실행하므로 학습률·PPO epoch·데이터 재사용량을 다시 맞춰야 한다. 그래프는 해당 설정에서의 성능 변화로 읽는다.

13-2 / 29

벽시계 시간의 감소

시뮬레이션, 정책 추론, 학습을 GPU에서 이어 실행하면 CPU–GPU 자료 복사와 순차 시뮬레이션의 병목을 줄인다. 같은 환경 단계 수라도 실제 소요 시간이 달라진다. 속도 비교에는 사용한 GPU와 병렬 환경 수가 필요하다.

13-2 / 30

현실 로봇 검증

훈련 곡선이 높아도 실제 로봇은 마찰·충격·지연이 다르다. 다양한 지형에서 명령 추종, 넘어짐, 에너지 사용을 평가해야 sim-to-real 전이를 확인할 수 있다. 시뮬레이터 성능과 현실 성능을 같은 축의 숫자로 혼동하지 않는다.

병렬화의 교훈

GPU 병렬화는 학습에 필요한 경험을 빠르게 모으는 방법이다. 대량 batch는 PPO의 안정성을 도울 수 있지만 실제 환경과의 차이를 없애지는 않는다. 지형 무작위화와 제어 설계가 배포 성공에 함께 필요하다.

Rapid Motor Adaptation

RMA는 현실에서 알 수 없는 마찰·질량·지형 특성을 과거 관측과 행동의 이력에서 추정해 정책에 전달한다. 훈련 단계의 privileged 환경 정보와 배포 단계의 역사 기반 추정을 분리한다. RMA 논문

Blind walking

카메라 없이 관절 상태와 직전 행동으로 지형 변화에 반응한다. 100Hz 제어는 약 0.01초마다 행동을 갱신한다. 시각 정보가 없어도 접촉 뒤의 상태 변화에서 미끄러짐이나 높이 차이를 간접 추정할 수 있다.

13-2 / 34

훈련 때의 환경 인자

시뮬레이션에서는 질량·마찰·지형 같은 환경 인자 \(e_t\)를 알 수 있다. Encoder가 이를 잠재 벡터 \(z_t\)로 바꾸고 기본 정책 \(\pi(a_t\mid s_t,z_t)\)가 행동한다. 실제 로봇은 \(e_t\)를 직접 읽을 수 없으므로 이 경로 그대로 배포할 수 없다.

13-2 / 35

적응 모듈의 학습

최근 \((s,a)\) 이력 \(h_t\)에서 \(\hat z_t=g_\psi(h_t)\)를 예측해 시뮬레이션 encoder의 \(z_t\)에 맞춘다. 예컨대 \(\|\hat z_t-z_t\|^2\)를 줄인다. 중요한 것은 정확한 물리 파라미터 복원보다 정책에 필요한 정보를 이력에서 추정하는 것이다.

13-2 / 36

실제 배포

현실에서는 실제 관절 이력으로 \(\hat z_t\)를 만들고 기본 정책에 넣는다. 마찰이 바뀌면 몇 걸음의 결과가 이력에 반영되어 적응할 수 있다. 적응 속도는 이력 창, 관측 노이즈, 정책 제어 주기에 의해 제한된다.

적응의 동작 장면

서로 다른 지형의 영상은 같은 정책이 지형 조건에 따라 보행을 바꾸는지 보여 준다. 영상만으로 원인을 단정할 수는 없으므로 적응 모듈을 제거한 비교와 넘어짐 비율도 확인한다.

13-2 / 38

RMA의 교훈

Domain randomization으로 여러 환경을 경험하고, 이력 기반 모듈로 현재 환경의 잠재 특성을 추정한다. 시각 없이도 일부 지형 변화에 대응하지만 관측 이력으로 구별할 수 없는 조건은 즉시 알 수 없다. 실제 배포의 강건성은 평가 지형 범위에 묶인다.

Parkour 과제

걷기보다 복잡한 점프·기어가기·오르기는 장애물의 형태를 알아야 한다. 시각과 제어를 결합하고, 어려운 기술을 단계적으로 학습하는 방법을 본다. Robot Parkour Learning

한 정책으로 여러 기술

장애물 높이·틈·벽의 위치가 달라지면 다른 동작이 필요하다. 각 장애물에 별도 수동 정책을 전환하는 대신 하나의 정책이 관측에 따라 기술을 선택하고 실행하도록 한다. 새 장애물에 대한 일반화가 핵심 평가다.

13-2 / 41

관측의 범위

몸체 속도, 관절 상태, 직전 행동과 환경의 장애물 정보가 사용된다. 일부 환경 정보는 훈련 때만 주어질 수 있으므로 배포 정책이 실제로 무엇을 보는지 구분한다. 훈련의 privileged 정보가 배포 입력에 그대로 남으면 비교가 잘못된다.

13-2 / 42

부드러운 동역학으로 시작

처음에는 넘어짐·접촉 제약을 완화한 soft dynamics에서 앞으로 가는 행동을 배운다. 보상에는 전진, 행동의 매끄러움, 생존, 제약 위반 벌점이 들어간다. 이 단계는 어려운 점프의 유용한 초기 정책을 만든다.

쉬운 조건의 기술 생성

완화된 물리 조건에서 여러 장애물 행동을 경험해 초기 성공 표본을 얻는다. 실제처럼 엄격한 접촉 조건을 처음부터 적용하면 성공이 거의 없어 학습 신호가 약할 수 있다. 교육과정의 시작 지점을 만드는 단계다.

장애물별 동작의 분화

지나야 할 장애물에 따라 뛰기·기어가기·회피가 달라진다. 영상의 다양한 동작은 상태 조건부 정책이 행동을 바꾼 결과다. 모든 동작이 같은 성공률을 가지는지는 과제별 평가로 확인한다.

실제에 가까운 조건으로 fine-tune

Hard dynamics로 옮기면 접촉과 실패 조건이 엄격해진다. Soft 단계의 정책을 초기값으로 쓰고 실제 물리에 가까운 환경에서 다시 학습한다. 단순히 보상을 키우는 것이 아니라 전이·제약 자체가 달라진다.

기술별 성능

점프 높이, 틈 넘기, 낮은 장애물 통과 등으로 기술을 나누어 측정한다. 평균 한 값만으로는 어려운 동작의 실패를 가릴 수 있다. 장애물 크기와 초기 속도 범위를 함께 기록한다.
